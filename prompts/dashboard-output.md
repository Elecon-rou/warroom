# Dashboard output contract

Return compact JSON: {"title":"Dashboard title","widgets":[{"title":"Widget title","type":"number","source":"metrics","query":"verified expression"}]}. Root version/id/range/refresh default to 1/generated/selected range/0. Each widget id defaults to an assigned unique id, width=1, reducer=last, valueField/labelField/unit="", min=0,max=100,warning=70,critical=90. Use these defaults for required fields; width=1 adapts to content, width=2 prefers a wider tile, width=3 is a full row. Prefer width=1 for normal charts; reserve full rows for dense logs/tables or explicit user requests. Optional chartStyle="lines"|"bars" and axisMode="auto"|"fixed". Other allowed fields are those listed in skills. Always include title/type/source/sourceId/query per widget. source is the language kind; sourceId must be the exact configured source ID from available_sources. Discover each selected source independently. Never combine tenants or guess a sourceId. Explicit configuration must be valid. No markdown or prose.
