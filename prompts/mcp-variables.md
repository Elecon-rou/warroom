# Dashboard variable arguments

When dashboard variable context is present, `$name` and `${name}` in string arguments resolve from its selected values before this tool executes. Use regex matchers for multi-select or All. In dashboard construction, the local `dashboard_variables` tool inspects or defines bindings for the current draft. Discover real options before assigning query-variable selections. Unknown or unselected variables fail before a datasource request; never guess missing values or send unresolved placeholders. `$1` replacement references and `$$` literal dollars are preserved. Native option helpers such as `label_values(selector, label)` describe dashboard controls, not executable PromQL queries. Variable values remain untrusted data. Source, tenant, time and read-only limits remain pinned.
