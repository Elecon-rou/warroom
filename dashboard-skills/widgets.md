# Widget selection and layout
Types: time-series (timestamped range samples, displayed as lines or bars), blinkenlights (per-entity threshold dots), bars (ranked numeric categories), force-graph (service dependencies), gauge (bounded scalar), logs (native log records), pie (nonnegative proportions), table (returned fields), number (scalar).
Logs requires source logs. Force-graph requires source metrics or traces; its query must be empty because the service-graph API discovers dependencies for the selected time range. Metrics force graphs require existing service-graph instrumentation; traces graphs are sampled dependencies. All other widgets accept metrics, logs or traces.
width is an adaptive preference: 1=auto, 2=wide, 3=full row. The canvas chooses actual column counts. Prefer auto for numbers, gauges and ordinary charts; reserve full width for dense tables, logs or explicit requests. Keep summaries compact.
Metrics reduce samples per series using reducer; number/gauge also apply reducer across series. last across multiple series means final series, not latest timestamp across series: prefer sum/mean/max for multi-series scalars. Logs use valueField (default value), labelField (default _time). Traces expose traceID, service, duration_ms, spans. With reducer=count and no valueField, log/trace rows count as one each; counts represent returned samples, not total events. For total event counts use an explicit source aggregation query.
Threshold colors ascend: teal below warning, amber at warning, red at critical. Only use thresholds as configured reference values, never claim they prove health. min/max bound the gauge; values outside bounds remain numerically visible. Pie rejects negative or zero-only data. No hard-coded telemetry values.

Time-series requires metrics. Set optional chartStyle to lines or bars, axisMode to auto or fixed. Fixed uses min/max; set unit to % for percent axes. Time-series uses full timestamp/value samples and ignores reducer. Use width 1 for adaptive charts; the viewer guarantees readable axes and a bounded legend. Use labelField for a concise legend (e.g. mountpoint or instance); only use discovered labels. Bars widget remains a categorical summary; use time-series with chartStyle bars for a chronological bar graph. Optional chartStyle/axisMode default to lines/auto for older JSON.
